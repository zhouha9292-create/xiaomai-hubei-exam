=====================================================
   小麦课 - 湖北成人高考学校查询网站 使用说明
=====================================================

【文件说明】
  index.html          → 主网页文件（双击即可在浏览器打开）
  data.js             → 数据文件（网站自动加载）
  convert_excel.py    → Excel数据导入工具
  湖北成人高考学校数据.xlsx → 示例数据文件

【如何替换为你自己的Excel数据】

  第一步：准备Excel文件
  - 确保Excel包含以下列（列名必须一致）：
    学校名称 | 办学层次 | 专业名称 | 专业类别 | 学习形式 | 学制 | 所在城市 | 学费 | 招生人数
  - 办学层次取值：高起专 / 高起本 / 专升本
  - 专业类别取值：文史类 / 理工类 / 经管类 / 法学类 / 教育类 / 医学类 / 艺术类
  - 学习形式取值：函授 / 业余 / 脱产

  第二步：运行转换命令
    打开终端，执行：
    python convert_excel.py 你的文件.xlsx data.js

  第三步：刷新网页
    - 如果用浏览器直接打开index.html → 刷新页面即可
    - 数据会自动更新

【网页功能说明】
  - 支持按学校名称、办学层次、专业类别、学习形式、城市筛选
  - 支持关键词模糊搜索
  - 结果分页展示，每页15条
